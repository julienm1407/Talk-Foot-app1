# Captures d’écran stores

Place ici les visuels avant upload Play Console / App Store Connect.

## Google Play

| Asset | Dimensions | Fichier suggéré |
|-------|------------|-----------------|
| Icône | 512 × 512 PNG | déjà généré (`mobile/assets/icon.png`) |
| Feature graphic | 1024 × 500 PNG | `feature-graphic-1024x500.png` |
| Phone | min. 1080 × 1920, max 8 | `phone-01-accueil.png`, … |
| Tablette 7" | 1200 × 1920 | optionnel |
| Tablette 10" | 1600 × 2560 | optionnel |

## App Store

| Device | Dimensions |
|--------|------------|
| iPhone 6.7" | 1290 × 2796 ou 1284 × 2778 |
| iPhone 6.5" | 1242 × 2688 |
| iPhone 6.1" | 1179 × 2556 |
| iPad Pro 12.9" | 2048 × 2732 |

## Scènes recommandées

1. Accueil avec matchs live
2. Salon / canal match (score + chat)
3. Tribune / tifo
4. Profil + avatar modulaire
5. Débat ou groupe supporters

Astuce : lancer `npm run build:mobile`, puis émulateur Android ou simulateur iOS, captures PNG natives.
